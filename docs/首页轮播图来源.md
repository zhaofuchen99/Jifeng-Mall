# 首页轮播图片来源说明

`docs/sql/jifeng-mall-init.sql` 的种子数据给 `banner` 表配了三条轮播，`image_url` 指向：

- 轮播 1「新品首发 · 极锋商城」→ `/upload/banner/banner-1.png`（深蓝 → 紫）
- 轮播 2「手机专享 · 立减不止一点」→ `/upload/banner/banner-2.png`（暖橙 → 红）
- 轮播 3「限时秒杀 · 每天一场」→ `/upload/banner/banner-3.png`（暗红 → 朱红）

这三个文件**不在仓库里**（图片是二进制资源，不进仓库），需要放到 `my.upload.location`
指向的目录，即 **`d:/shoplook2026/upload/banner/`**。

## 生成方式

`tools/assets/gen_banner_img.py`（纯标准库手写 PNG，2 倍超采样抗锯齿）直接生成，**不使用任何外部素材，
因此没有版权问题**：

```bash
python3 tools/assets/gen_banner_img.py   # 输出到 d:/shoplook2026/upload/banner/
```

输出目录 `OUT_DIR` 硬编码为 `/mnt/d/shoplook2026/upload/banner`（WSL 路径），
部署形态变了需要改脚本里的这一行。

三条轮播共用同一套版式，只换配色：对角渐变打底 + 两团柔光 + 右侧同心圆环 + 一道斜向亮带 + 暗角。
圆环压在右侧，左侧留白给前端叠的标题文字。

## 为什么图上不写字

纯标准库里没有中文字体，硬画汉字只会很难看。**标题由前端用 HTML 叠在图上**
（`mall-web/src/views/Home.vue` 的 `.banner__text`），所以这里只画「背景美术」。
改标题不用重新生成图片——改后台「商品管理 - 轮播管理」里的记录即可。

## 前端显示约定

- 轮播图用 `object-fit: cover` —— 轮播是**背景板**，裁切不影响信息。
  这与商品图相反：商品图必须 `contain`，见 `docs/商品图来源.md`。
- `imageUrl` **可以为空**。为空、或图片 404 时（`<img>` 的 `onerror` 会把图藏起来），
  露出底下的渐变兜底，不会出现破图。所以轮播图片不是必填项。
- 文字压在图上时左侧有一层黑色渐变，保证任何配图下标题都读得清。
