# 演示商品图片来源说明

`docs/sql/jifeng-mall-init.sql` 的种子数据把两个演示商品的 `pic` 指向：

- 商品 1「iPhone 16 Pro」→ `/upload/good/iphone.png`
- 商品 2「Mate 70 Pro」 → `/upload/good/mate.png`

这两个文件**不在仓库里**（图片是二进制资源，且下节说明的版权原因不宜入库），
需要手工放到 `my.upload.location` 指向的目录，即 **`d:/shoplook2026/upload/good/`**。

## 当前使用的图片

| 文件 | 来源 | 规格 |
| --- | --- | --- |
| `iphone.png` | Apple iPhone 16 Pro 产品渲染图（三摄 / 原色钛金属，正反面） | 1500×1500 PNG |
| `mate.png` | 华为官网 HUAWEI Mate 70 Pro 产品图（云杉绿，正反面）<br>`consumer.huawei.com/content/dam/huawei-cbg-site/common/mkt/pdp/admin-image/phones/mate70-pro/list/green.png` | 756×960 PNG（透明底） |

两张图都是**正反面并排**的构图，风格统一。

## ⚠️ 版权提示

这两张是**厂商官方营销素材**，商标与著作权归 Apple / 华为所有。

- 用于**本地教学演示、课程作业**：属于常见的合理使用场景，一般无实际风险；
- 若要**公开发布**（传到 GitHub、部署到公网、用于商业用途）：属于侵权，**必须先换成
  有明确授权或自由许可的图片**。

需要许可干净的替代方案时，可从以下图源找（均为自由许可）：

- **Wikimedia Commons** — `https://commons.wikimedia.org/`（CC BY-SA / 公有领域）
- **Openverse** — `https://api.openverse.org/v1/images/?q=<关键词>&license_type=commercial`（免密钥）

注意这两处的实拍图质量普遍不如官方渲染图（多为店内实拍、手持、有反光），
实测搜「iPhone 16 Pro」可用的大多是这种，作为商品主图观感较差。

## 备用的程序生成图

`D:\gen_goods_img.py`（纯标准库手写 PNG，2 倍超采样抗锯齿）可以生成两张手机示意图。
不需要任何外部素材、无版权问题，但观感是示意图而非商品照。官方图不可用时可以拿它顶：

```bash
python3 /mnt/d/gen_goods_img.py     # 直接覆盖 d:/shoplook2026/upload/good/ 下的两个文件
```

## 前端显示约定

商品图一律用 `object-fit: contain`（见 `mall-web/src/styles/main.css` 及各页面的 `.thumb`），
**不要用 `cover`** —— 商品图不能裁切，`cover` 会把竖版图（如 756×960 的华为图）上下切掉。
图片容器底色为 `#fff`，避免白底商品照在浅灰底上露出方块边界。
